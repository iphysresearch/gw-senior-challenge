03 赛题与数据 / Task & Data

任务 The task

数据集是一段模拟 + 真实 O3a 噪声的探测器应变流：采样率 2048 Hz、低频截止 20 Hz，按每 8 秒 切成一个评测窗（16384 点/窗），共 1200 个测试窗。部分窗注入了双黑洞并合信号，部分只有噪声或瞬态伪信号(glitch)。请判断每个窗是否含引力波信号。 A 1-D detector strain stream (2048 Hz, 8 s windows, 1200 test windows). Some windows contain binary-black-hole merger signals; decide, per window, whether a signal is present.

提交格式：每个窗一行 id,prediction，prediction = 该窗含信号的显著性/概率（越大越像有信号）。 Submit one row per window: id,prediction, where prediction is the signal significance/probability.

评分 Scoring

对全部 1200 个测试窗计算单一 ROC-AUC，得分即：

得分 Score = AUC × 100

纯客户端计算，采用平均秩 AUC，与 sklearn roc_auc_score 逐位一致。基准：全 0.5 → 50 分；完美排序 → 100 分。 Single ROC-AUC over all 1200 windows, ×100. Computed in-browser, matching sklearn's roc_auc_score.

快速上手 Quick start

用 Python 读取应变流并生成提交：

import numpy as np, csv
x = np.load("test_strain.npy")          # (1200, 16384)
pred = your_detector(x)                  # 越大越像有信号
with open("submission.csv","w",newline="") as f:
    w = csv.writer(f); w.writerow(["id","prediction"])
    for i,p in enumerate(pred): w.writerow([i, float(p)])
